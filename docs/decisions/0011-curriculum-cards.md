# ADR-0011: 교재 카드 — 자주 쓰는 교재는 단원 구조를 들고 있고, 계획은 그 단원 순서로 짠다

- 상태: 제안 (2026-10-20)
- 관련: ADR-0010(자료 조사 파이프라인), ADR-0007(마일스톤·주기 커서),
  [`docs/experiments/l0-materials-source-results.md`](../experiments/l0-materials-source-results.md)
- 구현: `domain/curriculum.py` · `domain/curriculum_cards/toeic.json` ·
  `orchestrator/curriculum_plan.py` · `POST /plans/materials/curriculum-confirm` ·
  `study-method` 응답 `curatedBooks` · 기준선 `scripts/toeic_baseline.py` ·
  §5 `curriculum_plan.books_from_materials` · `interview_adapter._material_items`

## 배경

"토익 700점, 해커스 책으로" 라고 해도 계획이 책을 따르지 않았다. 원인은 두 겹이다.

1. **목차를 못 얻는다.** 알라딘 API 목차 0/10, 국중 seoji 해커스 0/3, 크롤링 차단(L0). 확정된
   해커스 책에 대해 분해 프롬프트가 받는 건 "총 556쪽, 세션당 약 18쪽" 뿐이다.
2. **얻어도 LLM 순응에 달려 있다.** 자료를 "참고"하라는 프롬프트는 어길 수 있고 어겨도 조용하다.
   첫 계획 이후 회차를 채우는 `continuation_fill` 은 자료를 아예 받지 않는다.

기준선(`scripts/toeic_baseline.py`, 550점 → 700점 · 8주 · 주 4회 60분, 4주 주기):

| 시나리오 | 세션 | 책 단원을 가리키는 세션 | 시험 파트만 언급 | 자리표시자 |
|---|---|---|---|---|
| 자료 없음 (LLM) | 16 | **0** | 8 | 0 |
| 해커스 VOCA 쪽수만 (LLM, 지금 경로) | 16 | **0** | 4 | 0 |
| 교재 카드 700+ (이 ADR) | 16 | **16** | 0 | 0 |

쪽수만 준 계획은 책에 없는 "Voca 1~4세션" 이라는 단위를 지어냈고, RC 는 통째로 빠졌다.

## 결정

### 1. 자주 쓰는 교재는 카드로 들고 있는다

`domain/curriculum_cards/<시험>.json` — 책마다 단원 순서·종류(학습/점검/모의고사/부록)·짧은
주제어·추정 분량. 첫 묶음은 토익 10권(해커스 기출 VOCA·700+·RC/LC 기본서·왕기초 RC/LC, ETS
단기공략 750+·기출 1000 Vol.5 RC/LC, 해커스 실전 1000제 1 RC).

- 출처는 예스24 공개 목차(2026-10-20). **구조와 분야 이름만** 옮기고 목차 문장·설명은 옮기지
  않는다(`test_card_topics_stay_short`).
- 한 권짜리 교재(LC·RC·VOCA 병행)는 단원에 갈래(`track`)를 달고 카드의 단원 순서를 **병행
  순서**로 적는다 — 700+ 는 "LC DAY n · RC DAY n · VOCA DAY n" 을 하루씩.
- 분량(`minutes`)은 추정치다. 실제 수행 시간으로 보정하는 건 학습자 프로필 단계의 몫이다.

### 2. 카드가 확정된 목표는 LLM 대신 규칙이 마일스톤·세션을 만든다

- Stage A — 책마다 단원을 N 등분해 같은 번호끼리 묶은 **단계**가 마일스톤이다. 통짜 모의고사는
  마지막 단계로 모은다. N 은 주기 수의 배수(`phase_count_for`) — 주기마다 같은 몫을 받게.
- Stage B — 이번 주기 마일스톤 창의 단원을 세션 수에 **고르게** 펼친다(`spread`). 단원은 절대
  버리지 않는다 — 시간이 모자라면 세션당 필요한 분을 고지한다.
- 검토 LLM 도 건너뛴다 — 결정적 계획이라 반려→재분해가 아무것도 못 바꾼다.

### 3. 다음 주기는 마일스톤 커서로 이어간다 — 진도 저장소를 새로 만들지 않는다

단계는 단원 **개수로** 나누므로 같은 교재·같은 단계 수면 언제 다시 계산해도 같다. 2주기에는
영속된 마일스톤 개수에서 단계 수를 역산해 같은 단계를 만들고 **위치로** 짝짓는다. 어디서부터
이을지는 기존 커서(ADR-0007)가 안다.

사용자가 마일스톤을 추가·삭제했으면(제목이 절반 이상 달라졌으면) 카드 경로를 포기하고 기존 LLM
분해로 넘어간다 — 사용자가 고친 뼈대를 덮어쓰지 않는다. 그때도 카드 목차가 `materials_note`
텍스트로 실려 LLM 이 참고한다.

### 4. 추천은 규칙 — 현재 점수와 목표 점수만 본다

| 조건 | 기본 선택 | 대안·선택 |
|---|---|---|
| 지금 450 미만 · '처음' | 왕기초 RC·LC + 기출 VOCA | 한 권짜리 |
| 목표 750 이하 | 구간에 맞는 한 권짜리 | 기출 VOCA · 다른 한 권짜리 · 기본서 |
| 그 위 | RC·LC 기본서 + 기출 VOCA | 한 권짜리 |

모의고사집은 언제나 선택으로만 보인다. 한 권짜리를 고를 땐 단어장을 기본으로 고르지 않는다 —
단어 DAY 가 이미 있고, 700+ 하나로 8주 × 주 4회 × 60분이 꽉 찬다.

### 5. 목차 있는 도서·재생목록도 같은 배정기를 탄다 (2026-10-22, api-change-log v2.39)

카드가 없어도 사용자가 확정한 자료에 단원 구조가 있으면 — 국립중앙도서관 목차가 온 책, YouTube
재생목록 — 그 목록을 카드와 같은 `Book`/`Unit` 으로 바꿔(`curriculum_plan.books_from_materials`)
같은 단계 나누기·펼치기를 쓴다. 텍스트로 LLM 에 넘기던 때는 단원 경계를 세션 수에 맞춰 쪼개고 합치거나
목록에 없는 세션을 끼웠다(재생목록 16세션 중 4개).

- 확정본에서 단원이 3개 이상인 자료만 outcome 목표의 `material_items` 로 옮긴다(heaviest 만, 카드처럼).
  다음 주기도 같은 outcome 을 시드로 쓰므로 그대로 이어진다.
- 단원 분량: 영상은 재생 길이, 책은 장 쪽수 × 쪽당 시간. 쪽당 시간은 확정 화면이 보여 준 진도
  (`pages_per_session`)에서 나오고, 없으면 2분/쪽으로 어림한다.
- 한 번 길이의 1.5배가 넘는 단원은 나눈다("10강 (3/10)"). 카드 단원은 처음부터 한 번 크기라 나눌 일이
  없지만 영상 한 편·책 한 장은 아니다(실측 재생목록 10편째가 617분).
- 영상 주제는 **이웃 영상과 겹치는 머리·꼬리를 뗀** 나머지다 — 대괄호 속만 고르면 "[해커스] …"
  채널 꼬리표를 주제로 잡고, 전체 공통 머리만 떼면 시리즈 끝에 성격이 다른 영상 하나가 붙었을 때
  시리즈 머리말이 모든 주제에 남는다.
- 세션 배치는 카드와 같은 **개수 기준** 펼치기다. 단원 길이가 들쭉날쭉하면 짧은 단원 둘이 한 세션에
  들어가기도 한다(실측 1세션 = 1강 54분 + 2강 67분). 분 기준 펼치기는 카드 계획까지 바꾸므로 보류했다.

## 하지 않은 것 / 다음

- **사용자 성향은 아직 안 본다**(강의 선호, 실제 완료율, 미룬 단원). 학습자 프로필 단계에서
  추천과 세션 길이에 반영한다.
- **단원 단위 진도**는 모른다 — 마일스톤 단위까지만 안다. 밀린 단원 재배분은 진도 저장소가 필요하다.
- 카드 밖의 **목차 없는** 책은 예전 경로(도서 검색 → 쪽수 기반)다(목차 있는 책·재생목록은 §5) — 검색 소스는 2026-10-21 알라딘에서 국립중앙도서관
  ISBN 서지정보로 바뀌었다(알라딘 Open API 2026-10-30 종료, api-change-log v2.38). 앱 안에서 목차 사진을 받아 구조를 뽑는
  길은 LLM 이미지 입력·업로드 경로가 둘 다 없어 이번 범위 밖이다.
- 응답 `aiSource` 는 교재 카드 마일스톤에서 `"rule"`, 계획에서는 기존 판정(`"llm"`)을 따른다 —
  FE 가 "규칙 기반 = 오프라인 모드" 로 안내하므로 계획 쪽은 별도 값(`"curriculum"`)과 배지가 필요하다.
